## 图 10–12 水源与供水

卡片 / 本单位与全市、类型与状态筛选、导入导出、地图模式、3 km 内最多 30 个在用水源、壳打开百度导航。供水：火点选点、附近水源而非全站、无车辆档案时默认泵量并写明、AI 失败保留本地结果。种子水源 0 条，空列表不挡走查，导入后才有图 10/11 点位。

## 图 13 重点单位 — 缺口

后端：7 类 CRUD、COS 预签名、预览 URL。H5：`#/key-units`、`#/key-units/:id` 未挂载。规格还要求资料/预案/水源浮动入口、PDF 内预览。

## 图 14–16 危化品 / AI / 天气

危化品：名称/俗称/UN/CAS + 图/文走本后端，免责文案在页上。AI：未撤出人员白名单 + 天气摘要，禁止电话与完整花名册。天气：后端代理；罗盘走 `bridge.heading()`，鸿蒙一期 `UNSUPPORTED` 时提示。天气客户端仍为模拟实现（P7 已记），走查标能力在、数据源待接真 API。

## 图 17–18 二维码共享 — 缺口

后端：站级 `POST /share` 默认 2 小时、可作废；令牌 SHA-256 入库；匿名 `GET /api/v1/s/{token}` 返回 `ShareAttackVO`（站名、更新时间、编组、姓名、规格、压力、剩余、状态；无电话/NFC/账号）。拦截器已排除该匿名路径。

缺：

1. APP 内 `#/share` 页（出码、展示过期时间、作废）。
2. 微信可打开的 HTML 页。当前 `shareUrl` 指向 JSON API，微信扫码不是「查看人员状态」页。
3. 对外页 WS / 短轮询（规格 F14）。
