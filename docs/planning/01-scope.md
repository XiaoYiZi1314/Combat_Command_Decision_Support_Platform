# 一期范围与权限

## 1. 产品一句话

作战指挥辅助决策平台：站级在现场管内攻人员与空呼风险，大队/支队看实时汇总。交付是 **安卓 APK + 鸿蒙兼容验证（HAP 紧随）** 和 **腾讯云独立 Java 后端**。没有 PC 端。

## 2. 一期做

来自需求文档，并按现网手感补齐操作细节（不扩到源码里的二期模块）：

1. 登录与四级账号（站 / 大队 / 支队 / 开发者）
2. 站级内攻：快速录入、NFC 扫描入场、人员卡片、复测压力、撤出
3. 空呼剩余时间与安全 / 预警 / 危险 / 已撤出
4. 花名册与战斗编组（含手填 NFC 编号、Excel 导入导出）
5. 支队 / 大队实时态势（只显示有未撤出人员的站）
6. 云同步：WebSocket 为主，断线拉取；站级离线补传
7. 值班表
8. 水源档案、地图、最近水源
9. 供水计算
10. 重点单位预案
11. 危化品查询 + 拍照/文字 AI
12. AI 辅助研判
13. 天气与方位
14. 二维码共享（有时效只读令牌，微信可扫）
15. 空呼时间计算器（需求第 3 节的参数来源，现网已有独立页）
16. 参数设置（阈值、默认强度、语音开关、退出登录）
17. 模块化 H5 + 安卓壳；鸿蒙桥验证

## 3. 一期不做（源码有、需求一期没有）

| 现网入口 | 处理 |
|----------|------|
| 车辆档案 | 隐藏 |
| 文书生成 | 隐藏 |
| 内攻历史记录 | 隐藏 |
| 批量 NFC 登记 | 隐藏；入场仍做单次 NFC |
| 测试 / 训练 / 出警模式 | 不做；指挥端看「有未撤出卡片」的站 |
| 车辆审批 / 水源审批流 | 不做 |
| 融合通信自动拉值班 | 不做，值班手填 |
| PC 指挥台 | 不做 |
| APP 直连 R2 / Agnes / 旧 `nxgk-file` | 禁止 |

## 4. 角色

| 角色 | 登录后看见 | 可写 | 只读 |
|------|------------|------|------|
| 站级 | 本站内攻主界面 | 本站内攻、花名册、编组、水源、预案、值班、本站设置 | — |
| 大队 | 下属站汇总；点进单站看组与卡片 | 无档案写权限 | 下属站全部一期数据 |
| 支队 | 全市有内攻的站汇总 | 无档案写权限 | 全市一期数据 |
| 开发者 | 与支队相同视角 + 内部诊断 | 编制不在 APP 里改 | 用于排障 |

编制（大队、站、账号）由后端种子数据写入。大队账号禁止删除。

## 6. 迁移

优先迁入后端：花名册、战斗编组、水源、重点单位预案、值班。

放弃并记清单：进行中的内攻状态、R2 对不上的对象、车辆与历史归档。

## 7. 红线（规划层）

- APP 不持有 COS / 地图 / AI 密钥
- 口令后端哈希，首次登录强制改密
- 共享页不含电话等花名册敏感字段
- 空呼时间、风险、AI 只作辅助，界面保留「不替代现场指挥」
