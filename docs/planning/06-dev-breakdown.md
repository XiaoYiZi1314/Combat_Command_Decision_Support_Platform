## 验收（最小实战）

- 站级账号改密后能录入本组、NFC 或手选入场、复测、撤出
- 断网仍能改压力，恢复后指挥端看到
- 支队只看到有人在场的站，点得进只读卡片
- 微信扫共享码能看态势，看不到电话
- APK 反编看不到 COS/AI/地图密钥
