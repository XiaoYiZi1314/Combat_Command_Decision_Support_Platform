## 4. 水源

详见既有 [p6-water-migration-waiver.md](p6-water-migration-waiver.md)。结论不变：

- 现网引用 `water_sources_manifest.js`，源码包中文件不存在，`WATER_SOURCE_MANIFEST` 运行时为空。
- R2 强制保留 ID（海河路 `municipal_001`、安顺路 `municipal_027/028/029`）本库无对应记录。
- **本期零条进库。**

落库通道已就绪：

- `POST /api/v1/stations/{id}/waters` 手工新建
- `POST /api/v1/stations/{id}/waters/import` 兼容现网检查记录表列（类别 / 辖区队站 / 设置方式 / 地理位置 / 使用状态 / 是否报修 / 备注 / 经度 / 纬度）
- 导出与模板：`/waters/export`、`/waters/template`

若后续拿到 `water_sources_manifest.js`，类型归一：`消防水鹤→crane`、`地上消火栓→ground`、`地下消火栓→underground`；状态归一：`好用→active`、`不好用/报修→repair`。
