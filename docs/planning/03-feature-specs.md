# 一期功能规格

规则：每个功能写清角色、主路径、字段、规则、失败态。数字默认沿用现网，除非下面改过。

---

## F0 登录、会话、编制

**谁用**：全部角色。

**主路径**
1. 冷启动若有未过期会话 → 按角色进 `#/attack` 或 `#/hq`。
2. 否则 `#/login`：账号、密码。
3. 首次登录（种子口令或管理员重置后）必须改密，新口令不少于 8 位。
4. 首次进入本机弹免责声明，同意后不再挡。
5. 拉编制与本账号可见站列表。

**规则**
- 站级只能进本站；切换站下拉对站级隐藏或只读本站。
- 大队只看见下属站；支队/开发者看见全部站 + 战勤保障分队。
- 连续失败 5 次锁定 10 分钟（后端计）。
- 会话：JWT 访问令牌 + 短 refresh；过期用 refresh 续，refresh 失效则重登。口令不放本地。

**失败**
- 账号不存在 / 口令错：不区分具体原因。
- 无网：允许用本机已有会话看离线缓存；新登录失败并提示。

## F1 站级内攻主界面

**谁用**：站级。指挥账号进单站详情时只读同款卡片。

**界面**
- 顶栏：支队名 / 本站名、设置。
- 四格统计只计本站当前人员：安全、预警、危险、已撤出。点格过滤列表。
- 主屏：人员卡片列表。空列表显示站徽与「暂无内攻人员」。
- 副屏：按战斗编组汇总人数与最差状态。
- 底栏：NFC 扫描。
- 主操作：快速录入、云同步、更多功能。

**人员卡片字段**
- 姓名、编组名、气瓶规格（6.8L / 9L）
- 当前压力（MPa）、已作业时间、估算剩余时间
- 状态：预录入 / 安全 / 预警 / 危险 / 已撤出
- 操作（仅站级）：入场、复测压力、撤出、删除（仅预录入或误录）

**状态机**

```
预录入 --确认压力+规格--> 内攻中(安全|预警|危险) --撤出--> 已撤出
内攻中 --复测压力--> 仍为内攻中（重算时间）
预录入 --删除--> 消失（不进指挥汇总）
```

**规则**
- 同一人同一时刻本站只能有一张未撤出卡片。再录则提示并聚焦已有卡。
- 临时人员（不在花名册）允许录入，姓名必填，最长 10 字，卡片标记「临时」。
- 指挥端不显示删除/录入。
- 已撤出保留在本站列表，变淡，不计入指挥端「正在内攻」。

**同步**
- 任何入场 / 复测 / 撤出写入本地后入离线队列，有网立即推后端。
- 「云同步」强制推一次并拉一次，给现场确认。

## F2 快速录入

**谁用**：站级。

**主路径**
1. 打开底栏面板，编组 Tab（含「全部」）。
2. 点花名册芯片多选；已在场的芯片灰掉。
3. 滑条设压力，选 6.8L / 9L。
4. 「确认预录入」生成预录入卡片。
5. 「一键预录入本组全部人员」= 该组未在场成员。
6. 临时人员：姓名 + 压力 + 规格 + 添加。

**规则**
- 默认压力 25 MPa。
- 有个人档案气瓶规格则带出，仍可改。
- 有早检压力（`morningPressure`）可作默认，仍可改。

---

## F3 NFC 入场

**谁用**：站级。壳提供读卡。

**主路径**
1. 点底栏或靠近标签。
2. 编号与本站花名册 `nfcTag` 精确匹配（去空白、大写）。
3. 匹配成功：
   - 已有未撤出卡 → 打开该卡复测。
   - 否则预录入；若档案有早检压力，可直接入场（沿现网文案）。
4. 未匹配：提示「未找到对应花名册」，可手选人员或取消。

**规则**
- 一期不做批量把标签写入档案。
- 无 NFC 硬件：隐藏底栏主按钮文案改为「本机无 NFC，请用快速录入」。

## F4 空呼估算与风险

**谁用**：卡片展示；计算器页用于标定个人曲线。

**默认阈值（可在设置改，按站保存）**

| 项 | 默认 |
|----|------|
| 压力预警 | 10 MPa |
| 压力危险 | 4 MPa |
| 时间预警 | 12 分钟 |
| 时间危险 | 5 分钟 |
| 默认强度 | 中 |
| 场景 | 平地 |

**判定（先到先得，取更严重）**
- 危险：压力 ≤ 危险阈值 **或** 剩余时间 ≤ 时间危险
- 预警：未危险，且压力 ≤ 预警阈值 **或** 剩余时间 ≤ 时间预警
- 安全：内攻中且未预警/危险
- 已撤出 / 预录入：不跑倒计时

**时间估算（沿现网模型，后端与 H5 用同一套常量）**
- 气瓶容积：6.8L / 9L
- 默认 RMV：低 41 / 中 55 / 高 68 L/min
- 有该人高强度实测标定时，用个人 K 值覆盖默认
- 场景系数：平地 1、高层 1.19、黑暗 1.09、大跨度 1.10、搜救 1.25
- 剩余时间随压力与已过时间每秒刷新
- 强制撤离参考：可用时间 × 0.8（计算器页展示，主卡用阈值色）

**语音**
- 进入预警 / 危险播报一次，同一人同一档 3 分钟内不重复。
- 设置可关。

**免责**
- 设置与计算器保留「辅助参考，不替代现场指挥」。

## F5 花名册与战斗编组

**谁写**：站级本站。指挥只读，可切单位。

**档案字段**
姓名*、职务、衔级、电话、气瓶规格*、NFC 编号、身高、体重、年龄、早检压力、空呼标定记录。

**编组字段**
组名*、成员（花名册人）、组内角色（组长/组员/站指挥员等）。

**规则**
- 本站姓名唯一。
- NFC 编号本站唯一；空允许。
- 导入 Excel/CSV：现网模板列；冲突以「姓名 + 本站」更新。
- 指挥单元 / 指挥组导入缺失时不得吞掉原指挥组（沿现网保护）。
- 删除在册人员：若有未撤出卡片，先撤出或禁止删。

## F6 指挥态势（大队 / 支队）

**首页**
- 只列出「至少 1 张未撤出卡片」的站（大队再过滤编制）。
- 站卡片：站名、内攻组数、安全/预警/危险人数、最后更新时间。
- 支队可将直属战勤保障分队与大队并列；大队不看非下属站。
- 数据超过 2 分钟未更新：时间变琥珀；超过 5 分钟变红，文案「请向现场核实」。

**下钻**
- `#/hq/station/:id`：只读主/副屏。
- 「返回主界面」回汇总，不退出登录。

**实时**
- WebSocket 订阅可见站。
- 断线 3 秒后改 5 秒轮询，重连后回到推送。

## F7 值班表

**谁写**：站级本站。指挥只读可切站。

**字段**
日期*、主官、副职、当日战斗编组快照或引用、备注。

**规则**
- 日历月视图；今日/明日快捷。
- 主官副职从本站花名册选。
- 保存即同步后端。
- 不做融合通信拉取。

## F8 水源档案与导航

**谁写**：站级本站。指挥只读。站级可切「本单位 / 全市」只读浏览全市。

**类型**：消防水鹤、地上消火栓、地下消火栓。

**状态**：在用、报修。

**字段**
名称*、类型*、所属站*、地址、经纬度、状态、备注、照片、档案材料（PDF）。

**能力**
- 卡片 / 地图 / 材料 三模式（沿现网）。
- 筛选状态、类型、关键词。
- 最近水源：定位后取半径 3 km 内在用水源，最多 30 个，按距离排序；打开百度导航（经壳）。
- 导入表格、导出模板；同步走后端不是 R2。
- 地图 AK 由后端代理。

**一期不做**：水源审批流、出水视频 AI 审核。

## F9 供水计算

**谁用**：站级算本站；指挥可选单位后只算不改档案。

**输入**
火点（地图选点）、火灾类型、燃烧面积、经验场景系数、干线长度、干线口径、参战单位列表。

**火灾类型**：住宅/一般建筑、商市场/人员密集、仓库/大跨度、高层、危化品/油品。

**经验系数**：1.1 / 1.2（默认）/ 1.3 / 1.4，文案沿现网。

**规则**
- 只把火点附近水源计入，不是该站全部水源（需求原文）。
- 一期无车辆档案：车辆供水能力用类型保守默认值，界面写明。
- 结果展示需求水量、推荐水源、缺口说明。
- 「AI 研判」走后端，失败仍保留本地计算结果。

## F10 重点单位预案

**谁写**：站级本站。

**字段**
名称*、地址、类别*、联系人、电话、备注、预案文件（doc/docx/pdf/txt）、预案正文、平面图。

**类别**：人员密集场所、高层建筑、地下建筑、危险化学品、文物古建、大跨度厂房、其他。

**规则**
- 上传后后端抽文本（失败则手贴）。
- PDF 在 APP 内预览；Word 尽量转预览，失败给下载。
- 文件 COS，APP 只拿短时 URL。
- 查看页保留「资料 / 预案 / 水源」浮动入口手感。

## F11 危化品

**检索**：名称 / 俗称 / UN / CAS，后端转发或缓存应急管理部库检索；APP 不直接打开无控外链（可后端给结果页）。

**AI**
- 拍照 / 图库 / 文字研判。
- 图和补充描述只送到本后端。
- 无网：禁用 AI，检索若无本地缓存则失败提示。

## F12 AI 辅助研判

**输入（自动带，可改）**
本站未撤出人员摘要（姓名、状态、压力、剩余时间、编组）、天气摘要、火点/描述（若有）。

**输出**
轮换、撤离、风险提示。文案标注辅助参考。

**禁止**
- APP 直连 Agnes。
- 把电话、精确家庭住址、完整花名册送进模型。

## F13 天气与方位

- 罗盘：壳给航向；无传感器则提示。
- 天气：后端代理定位天气（温、风、湿、气压、日出日落、小时预报）。
- 用于判断烟气方向，不替代气象台。

## F14 二维码共享

**谁开**：站级，针对本站当前内攻。

**规则**
- 后端发共享令牌：默认 2 小时，可提前作废。
- 对外页只读：站名、更新时间、编组、姓名、规格、压力、剩余时间、状态。
- 不含电话、NFC 号、账号。
- 微信内打开 H5；无 Token 或过期显示失效。
- 有人入场/复测/撤出，对外页经 WS 或短轮询更新。
