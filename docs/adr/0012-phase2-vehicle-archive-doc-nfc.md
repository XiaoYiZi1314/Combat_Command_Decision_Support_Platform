# 二期启用车辆档案、内攻历史、文书生成与批量 NFC

一期（阶段 0–10）按 `docs/planning/01-scope.md` 与 `p10-abandon-list.md` 将车辆档案、文书生成、内攻历史记录、批量 NFC 登记列为隐藏/放弃。阶段 10 收口后客户提出续建，二期按下列边界启用：

- **车辆档案**：站级只读并提交变更申请，支队/开发直接落档并审批。种子数据来自客户 APK 内置清单（378 台），不含审批流外的写路径。
- **内攻历史归档**：全部人员撤出后一键归档为快照（含人员压力与时间），归档即清空本站现役人员行；支持改信息、删除与 Excel 导出。
- **文书生成**：AI 文书四模板（火灾扑救/抢险救援/演练/安全检查），仅依据用户提交摘要行文，正文须人工核签。
- **批量 NFC 登记**：仅本地记录与「标签→人员编号」别名绑定，不写入档案；入场仍以单次 NFC 与档案精确匹配为准。

供水计算一期「无车辆档案按类型默认泵量」的规则保持不变，车辆档案不参与泵量推导。阶段 10 放弃清单中「车辆与历史归档不迁移 R2 旧数据」的决策不变：种子与归档均走本库 `ccds_*` 表。
